Proyecto Delfín: Índice de Violencia

Este proyecto tiene como objetivo predecir el índice de violencia en los municipios de México utilizando modelos de redes neuronales entrenados con datos del INEGI desde el año 2015 hasta 2025.

Como parte del proceso, se realizó un análisis exhaustivo de los datos que incluyó la exploración de gráficas, limpieza y preprocesamiento, generación de nuevas características, y la separación del conjunto de datos en entrenamiento y validación. También se llevó a cabo una búsqueda de hiperparámetros para optimizar el rendimiento del modelo.

El resultado de este proceso fue un modelo capaz de predecir patrones de violencia de forma geoespacial y temporal. Para facilitar la visualización de los resultados, se desarrolló una página web interactiva que muestra un mapa de la República Mexicana. En este mapa se reflejan los niveles de predicción por municipio según el mes y año seleccionados.

Este proyecto fue realizado como parte del Programa Delfín, con el objetivo de aplicar conocimientos en ciencia de datos, inteligencia artificial y desarrollo web para contribuir al análisis de problemáticas sociales desde un enfoque técnico y visual.
