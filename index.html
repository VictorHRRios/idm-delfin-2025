Proyecto Delfín: Índice de Violencia

Este proyecto tiene como objetivo predecir el índice de violencia en los municipios de México utilizando modelos de redes neuronales entrenados con datos de INEGI desde 2015 hasta 2025.

Como parte del proceso, se realizó un análisis exhaustivo de los datos que incluyó la exploración de gráficas, limpieza y preprocesamiento de datos, creación de nuevas características, y la separación del conjunto de datos en entrenamiento y validación. También se llevó a cabo una búsqueda de hiperparámetros para optimizar el rendimiento del modelo.(Libreta)

El resultado de este proceso fue un modelo capaz de predecir patrones de violencia de forma geoespacial y temporal. Para facilitar la visualización de los resultados, se desarrolló esta página web interactiva que muestra un mapa de la República Mexicana. En el cual se muestran las predicciones por municipio según el mes y año seleccionados.

Este proyecto fue realizado como parte del Programa Delfín, con el objetivo de aplicar conocimientos en ciencia de datos e inteligencia artificial para contribuir al análisis de problemáticas sociales.
